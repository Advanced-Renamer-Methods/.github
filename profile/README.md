# Advanced Renamer - Preview New Names Before You Apply Them

Advanced Renamer builds a new name for files you select and shows the preview before anything is written. Apply it only when every line in that preview is a name you want. Start with a copy of a small folder. Do not point it at Windows, Program Files, or any directory you did not create.

---

## Why It Stands Out

![Advanced Renamer previewing new names for a small folder the user copied](https://www.advancedrenamer.com/img/userguide4/settings_program.png)

Renaming one file is easy to undo. Renaming a hundred is how a shoot becomes Img_1 through a pattern you did not read. Advanced Renamer is for that second case, with the preview as the whole point. The method can add a date, a counter, or text from the existing name. The method is also happy to produce fifty identical names or to strip the only part that told you what the file was. The preview is where you notice.

Run it on a copy. If the preview is wrong, change the rule and look again. Applying is the write. There is an undo for some renames and no undo for a folder you also moved and then emptied. Leave system folders alone even if a file inside them looks badly named. Those names are often what an installer expects.

## Core Capabilities

- **A Preview Column:** Old name and new name, side by side, before you apply.
- **A Rule You Can Read:** A counter, a date, or a replacement you typed, not a surprise.
- **Your Folder:** Files you copied or you are sure you may rename.
- **Apply Is the Step That Writes:** Until then, the originals keep their names.
- **A Small First Batch:** A handful of files proves the pattern.

## Performance Tips

- Copy the folder first. Rename the copy.
- Read every line of the preview, not only the first.
- Refuse a rule that would give two files the same name.
- Never add C:\Windows or another system path to the list.

## Troubleshooting

- Two files would share a name? Do not apply. Add a counter.
- The names look right on line one and wrong later? Read the rest of the preview.
- You renamed the only copy? Restore from backup. If you have none, stop.
- A program cannot find its file? You renamed something it still expects. Put the old name back from the preview list if you still have it.
